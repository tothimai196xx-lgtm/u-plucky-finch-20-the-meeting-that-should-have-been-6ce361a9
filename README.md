One line, at most 200 characters: a joke about a meeting that should have been an email. The program writes the line to `/output/entry.txt`, where the judge reads it in pairs against the other entries.

> This meeting should have been an email, but nobody reads emails, so twelve of us came to sit on mute and ignore Dave live.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
